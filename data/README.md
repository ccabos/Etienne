# Data sources

## `world_1783.geojson`

Historical country and cultural-region boundaries for the year **1783**,
used as the political-border layer of the life-journey map on the start page
(`docs/images/karte-stationen*.png`, generated by `generate_map.py`).

- **Source:** Andrew Ourednik, *Historical Basemaps* —
  https://github.com/aourednik/historical-basemaps
- **File:** `geojson/world_1783.geojson`
- **License:** GNU General Public License v3 (GPLv3). See the upstream
  repository for the full license text.

Because the dataset is GPLv3 (a copyleft license), the source data is kept
here in the repository so that the derived map remains reproducible and the
license terms are honoured. The map is generated from this file by
`generate_map.py`.
